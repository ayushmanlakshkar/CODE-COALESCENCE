# Code Coalescence

[Code Coalescence](https://code-coalescence.netlify.app/)

## 🚀 Overview
Code Coalescence is the official website for our college-level hackathon. It provides participants with event details, schedules, and a seamless registration process. The platform is built using React, ensuring a dynamic and responsive user experience.

## 🌟 Features
- **Hackathon Details**: Information about the event, schedule, and participation guidelines.
- **Registration Portal**: Allows participants to register easily.
- **Real-time Updates**: Stay updated with event announcements.
- **Attractive UI/UX**: Designed with a modern and intuitive interface.
- **Mobile Responsive**: Optimized for both desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS
- **Icons & Animations**: Lucide Icons, Framer Motion
- **Deployment**: Netlify

## 🔧 Installation
To set up the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/ayushmanlakshkar/CODE-COALESCENCE
   ```
2. Navigate to the project directory:
   ```bash
   cd code-coalescence
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
